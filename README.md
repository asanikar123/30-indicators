# 30 Indicators of a Healthy Civilization / Democracy

An interactive discussion aid built for the Harvard Class of 1972 reunion
committee, prompted by NPR's September 15, 2026 story, ["State of U.S.
democracy reaches new low, report finds"](https://www.npr.org/2026/09/15/nx-s1-5969741/state-of-u-s-democracy-reaches-new-low-report-finds),
which covers International IDEA's *The Global State of Democracy 2026:
Democracy in an Age of Conflict*.

Open `index.html` (or the GitHub Pages site) for:

- **30 columns**, one per indicator, adapted from IDEA's GSoD framework
  (Representation, Civil Liberties, Rights & Equality, Rule of Law,
  Participation), with the six US indicators the 2026 report puts at
  50-year lows flagged.
- **A year slider with playback (1975 → today)**: 1975-2020 replays real
  measured US values from the GSoD Indices v5.1 dataset; 2021-2025 bridges
  to today's illustrative starting values; dotted marks show each
  indicator's measured 2020 value.
- **Click any column** for its 45-year measured line chart; the hero tile
  carries a sparkline of the overall measured index.
- **Six levers** (electoral integrity, press freedom, judicial
  independence, executive restraint, anti-corruption, civic cohesion),
  each anchored at an illustrative reading of where that arena stands
  today; drag to explore counterfactuals, or use the preset scenarios.
- On claude.ai, an **"Ask a question" chat** (Scholar / Witty / Unhinged
  modes) that answers with charts and can drive the page; the static
  GitHub Pages copy omits it automatically.
