# Data

## GSoDI_v5.1.csv
The full official **Global State of Democracy Indices, version 5.1** dataset from
International IDEA: 174 countries, 1975-2020, ~30 indicators of democratic
performance on a 0-1 scale (point estimates plus upper/lower confidence bounds).
This is the newest vintage that was publicly mirrored outside idea.int; obtained
from the mirror at
https://raw.githubusercontent.com/mrostamipoor/FinalProjectCSE564/0f085bc6deeabe651db6e935839c3695dbcc8ae5/static/data/GSoDI_v5.1.csv
Original publisher and documentation: https://www.idea.int/gsod-indices/
(International IDEA publishes the data free of charge; attribute International
IDEA, Global State of Democracy Indices when reusing.)

## gsodi_us_2015-2020.csv
United States rows (point estimates only) extracted from the file above,
2015-2020. The 2020 row provides the "measured 2020" dotted marks in
`index.html` (values scaled x100 and rounded).

## Known gap
IDEA's current dataset (v9, through 2024) with the revised 2023 framework
(Representation / Rights / Rule of Law / Participation, "Credible Elections",
"Economic Equality", "Freedom of the Press", etc.) is available only from
https://www.idea.int/gsod-indices/ - swap it in to replace the 2020 marks with
current measured values.
